Wo landen die Farben?

Die Vorschau zeigt live, wo deine beiden Werte landen: 1 färbt die Browserleiste über deinem Header, 2 ist der Startbildschirm, bevor dein CSS geladen ist. Beide liest du aus deinem eigenen Tool ab — nicht aus dem Logo.

1
Header-Farbe theme_color
Die Hintergrundfarbe deiner Kopfzeile. Im CSS meist --panel oder das background von header.
2
Seitenhintergrund background_color
Die Farbe deines Seitenkörpers. Im CSS meist --bg oder das background von body.
